
# Rebrand-Saja

VIP lisans doğrulama sunucusu ve Lua paneli projesi.

## Bilesenler
- `server.js`: Lisans API sunucusu
- `package.json`: Node.js proje ayarlari
- `main.lua`: Lua paneli icin giris noktasi

## Kurulum
Render uzerinde Node.js Web Service olarak calistirilir.
VIP anahtari `VIP_KEY` ortam degiskeniyle ayarlanir.
